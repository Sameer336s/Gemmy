# Changelog

All notable changes to Gemmy. The version code here must match
`versionCode` in `app/build.gradle.kts`.

## [1.0] — 2026-11-25 · versionCode 1

First release.

- Gemmy floats over the home screen and every app (system overlay, foreground service).
- Idle life: bobbing, breathing, blinking, looking around, waving, hopping, spinning,
  yawning, and falling asleep with a small "z" after about a minute untouched.
- Tap for a squish, hearts and a speech bubble; double-tap to spin; long-press for a
  menu with Dance / Nap (or Wake) / Hide.
- Drag anywhere with momentum, bouncing off the screen edges; the position is remembered.
- Three sizes (S / M / L), changeable while it is running.
- Optional start on boot.
- No internet permission, no analytics, no ads, no accounts. GPL-3.0.
